## Project Preview / 项目预览

**Synera: Synergy Auto-Arena** is a lightweight single-player PvE auto-battler game.

**Synera: Synergy Auto-Arena** 是一款轻量级单人 PvE 自走棋游戏。

The project is developed as a Programming Assignment project for the **Advanced Programming course at Nanjing University in 2026**.

本项目是 **南京大学 2026 年高级程序设计课程 PA** 项目。

It focuses on object-oriented game architecture, including a unified unit model, polymorphic hero skills, grid-based combat, BFS pathfinding, equipment systems, synergy effects, and JSON-based save/load support.

项目重点展示面向对象游戏系统设计，包括统一单位模型、多态英雄技能、网格战斗、BFS 寻路、装备系统、羁绊效果，以及基于 JSON 的存档与读档支持。
